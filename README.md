# KStudio

Windows 용 1인 사용자 스튜디오 — 스크린 녹화 + 스크린샷 + 주석 편집 + (예정) 이미지 편집/필터/누끼.

> 옛 이름: Screen Recorder. archive 된 [KimyoriPhotoShop](https://github.com/kimyori7/KimyoriPhotoShop) (JS 기반 Phase 1 완료) 의 이미지 편집 기능을 흡수하면서 더 넓은 도구로 발전 중.

## Run
```
pip install -e .[dev]
python -m screen_recorder
```

## Test
```
pytest
```
