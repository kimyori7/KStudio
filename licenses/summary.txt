KStudio — Third-Party Components (summary)
==========================================

KStudio uses the following third-party software. Each component retains its
own license; this section lists the projects, their licenses, and links to the
upstream sources. Full license texts for the copyleft components — GPL v3
(FFmpeg), LGPL v3 (Qt/PySide6), and MPL 2.0 (certifi) — and the FFmpeg
corresponding-source provision, follow this summary in this same file. The
permissive components (MIT / BSD / Apache-2.0 / ISC / HPND / PSF) are attributed
below with their license and upstream link; each project's full license text and
copyright notice are available at the linked source.

For the licenses of KStudio's own source code, see LICENSE.

--------------------------------------------------------------------------------
- Bundled binary: bin/ffmpeg.exe (invoked as a separate process).
- License: GNU General Public License v3 (GPL v3). This build is configured with
  --enable-gpl --enable-version3 and statically links x264, x265, and xvid.
- Exact build: ffmpeg 2026-04-19-git-de18feb0f0-essentials_build (gyan.dev).
- Corresponding Source (GPL v3 sec.6) and full build provenance: see the
  "FFmpeg - corresponding source & provenance" section later in this file.
- Full GPL v3 text: see the "GNU GENERAL PUBLIC LICENSE (v3)" section below.
